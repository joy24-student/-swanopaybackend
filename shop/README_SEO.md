## 🚨 CRITICAL REMINDERS

### Must Have
✓ HTTPS enabled on your server  
✓ robots.txt updated with domain  
✓ BASE_URL uses https://  
✓ mod_rewrite enabled (usually is)  

### Common Mistakes to Avoid
✗ Forgetting to update robots.txt domain  
✗ Not enabling HTTPS  
✗ Using HTTP in BASE_URL  
✗ Not submitting sitemap to Google  
✗ Hardcoding product/category links  

### For Best Results
→ Monitor Google Search Console weekly  
→ Check Core Web Vitals monthly  
→ Update product links throughout site  
→ Keep sitemap in robots.txt updated

FREQUENTLY ASKED QUESTIONS

Got Questions?

How does SwapnoPay match MFS payments automatically?

SwapnoPay uses an on-device regex SMS parser and real-time backend engine to read incoming bKash, Nagad, Rocket, and Upay transaction SMS notifications. It automatically extracts the TrxID and amount, matching it against your open orders.

Does SwapnoPay work when internet is unavailable?

Yes! SwapnoPay is built offline-first using Android Room local database queues. When internet disconnects, all POS sales, stock updates, and ledger entries continue working smoothly. Once online, it automatically syncs with Supabase cloud.

Can developers integrate SwapnoPay into existing websites?

Absolutely. We provide zero-SDK direct HTTP REST APIs, real-time WebSockets, HMAC-SHA256 webhooks, and a drop-in Hosted Checkout Widget compatible with Node.js, Python, Kotlin, PHP/Laravel, Go, and any standard HTTP client.

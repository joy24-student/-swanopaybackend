❓ FREQUENTLY ASKED QUESTIONS

Got Questions?

How does SwapnoPay match MFS payments automatically? expand_more

SwapnoPay uses an on-device regex SMS parser and real-time backend engine to read incoming bKash, Nagad, Rocket, and Upay transaction SMS notifications. It automatically extracts the TrxID and amount, double-matching it atomically against your open orders in 0.8 seconds.

Does SwapnoPay work when internet is unavailable? expand_more

Yes! SwapnoPay is built offline-first using Android Room local database queues. When internet disconnects, all POS sales, stock updates, and ledger entries continue working smoothly. Once online, it automatically syncs with Supabase cloud.

Can developers integrate SwapnoPay into existing websites? expand_more

Absolutely. We provide open REST APIs, WebSockets, webhooks, and official SDKs for Python, Kotlin, React, JavaScript, and PHP/Laravel.

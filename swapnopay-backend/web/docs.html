Platform Mechanism & Architecture

SwapnoPay unifies carrier MFS SMS verification on Android, merchant databases, and web checkouts into a high-speed settlement pipeline.

bolt Atomic Pattern Matching

Merchant Android workers intercept raw carrier MFS SMS (bKash, Nagad, Rocket, Upay) and perform atomic regex extraction of Transaction ID, amount, and sender phone.

lock Central HMAC & Ledger

Platform Owner Admin Supabase database manages API key peppered HMAC digests, platform fee accounting, idempotency guards, and centralized payment telemetry.

rss_feed Real-Time WebSockets

Express.js + Socket.io server emits instant payment_status events (PAID, FAILED, CANCELLED) to listening web checkout widgets.

Webhooks & HMAC-SHA256 Signature Security

SwapnoPay signs all outbound webhook notifications with HMAC-SHA256 in the X-SwapnoPay-Signature header (t=<timestamp>,v1=<hmac>).

Node.js Signature Verification (Zero SDK — Built-in node:crypto):

const crypto = require('node:crypto');

function verifySwapnoPayWebhook(rawBodyString, signatureHeader, webhookSecret) {
  const parts = Object.fromEntries(
    String(signatureHeader || '').split(',').map(p => p.trim().split('='))
  );
  if (!parts.t || !parts.v1) return false;

  // Replay protection: reject timestamps older than 5 minutes (300s)
  if (Math.abs(Math.floor(Date.now() / 1000) - Number(parts.t)) > 300) return false;

  const expected = crypto
    .createHmac('sha256', webhookSecret)
    .update(`${parts.t}.${rawBodyString}`, 'utf8')
    .digest('hex');

  return crypto.timingSafeEqual(Buffer.from(expected, 'hex'), Buffer.from(parts.v1, 'hex'));
}

Python Signature Verification (Built-in hmac & hashlib):

import hmac
import hashlib
import time

def verify_swapnopay_webhook(raw_body: str, signature_header: str, secret: str) -> bool:
    parts = dict(item.strip().split("=", 1) for item in signature_header.split(",") if "=" in item)
    ts = int(parts.get("t", "0"))
    sig = parts.get("v1", "")
    if not ts or not sig or abs(int(time.time()) - ts) > 300:
        return False
    signed_payload = f"{ts}.{raw_body}".encode("utf-8")
    expected = hmac.new(secret.encode("utf-8"), signed_payload, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, sig)

Enterprise Production Deployment & Go-Live Guideline

Mandatory production architecture, security controls, Android SIM Worker configuration, and reconciliation checklist.

Zero-SDK Standard

architecture 1. Direct HTTP REST + Hosted Widget

SwapnoPay requires zero third-party SDKs or CMS plugins. Your backend creates orders via standard HTTPS POST /v1/payment/create (or /v1/developer/sandbox/order) and directs customers to the hosted checkout URL or embeds widget.html inside an iframe.

key 2. Credential Isolation & Secret Storage

Store sk_live_... and whsec_... strictly in backend environment variables. Never bundle secret keys inside frontend SPAs, Android/iOS client apps, or public repositories.

smartphone 3. Dedicated Android SIM Bridge Setup

Run the SwapnoPay Merchant Android App on a dedicated device holding your active bKash (16247), Nagad (16167), Rocket (16216), or Upay (16268) SIMs. Grant RECEIVE_SMS permission and disable Android Battery Optimization so the foreground socket stays connected 24/7.

verified_user 4. Idempotent Order Fulfillment

Enforce a UNIQUE database constraint on both order_id and carrier trx_id in your database. Always verify the X-SwapnoPay-Signature header and confirm the paid amount matches your invoice total before fulfilling an order.

Direct HTTP REST & Checkout Widget Examples (No SDK Required)

Copy-paste production integrations using standard built-in HTTP clients for your stack.

🟢 Node.js 18+ (Native fetch — Zero NPM Dependencies) 
const crypto = require('node:crypto');

async function createSwapnoPayOrder() {
  const response = await fetch('https://pay.swapnopay.top/v1/payment/create', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'Authorization': 'Bearer sk_live_your_api_secret',
      'Idempotency-Key': crypto.randomUUID()
    },
    body: JSON.stringify({
      order_id: 'ORD-2026-9812',
      amount: 1250.00,
      customer_phone: '01712963652',
      payment_method: 'bKash',
      redirect_url: 'https://mysite.com/success',
      webhook_url: 'https://mysite.com/api/webhooks/swapnopay'
    })
  });

  if (!response.ok) throw new Error(`HTTP ${response.status}: ${await response.text()}`);
  const result = await response.json();
  console.log('Redirect checkout URL:', result.data.payment_url);
}
